로그인 정보는 이 페이지에 저장하지 않아요.

처음 한 번 설정한 뒤, 다음부터는 비밀번호만 입력해 로그인해요.

비밀번호는 복구되지 않아요. 별도로 기억해 두세요. 갱신할 때는 기존 비밀번호를 그대로 사용해요.

GitHub 연결키 준비 방법
  1. GitHub에 character-studio-data 저장소를 Private으로 만들고 README를 추가해요.
  2. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token으로 들어가요.
  3. Only select repositories에서 character-studio-data 하나만 고르고, Contents 권한을 Read and write로 설정해요.
  4. 만든 연결키를 위 입력칸에 넣어요. 연결키는 정한 비밀번호로 암호화돼요.
설정 파일에는 비밀번호와 연결키 원문이 들어가지 않아요.
